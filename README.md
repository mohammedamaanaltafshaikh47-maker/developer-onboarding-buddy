# Developer Onboarding Buddy

Turn any codebase into a guided, day-by-day onboarding path automatically.

## Problem Statement

When a developer joins a new team, they typically spend 2–4 weeks just orienting themselves: figuring out what the project does, which files matter, how data flows through the system,and where to start contributing.There is no shortcut until now.

## Our Solution

Developer Onboarding Buddy uses IBM Bob's Agent mode and parallel subagents to automatically analyze any codebase and produce a complete, structured onboarding experience in minutes.

Given a Git repository, the tool:

1. Analyzes the codebase structure entry points, modules, data flow, and tech stack and generates an architecture overview with a Mermaid diagram.
2. Mines the commit history identifies the top 10 "hot files" most frequently changed, which are the files a new developer must read first.
3. Generates a personalized day-by-day learning path a 5-day plan with reading lists, key concepts, hands-on tasks, and quizzes to verify understanding.
4. Adapts to the developer's level every day's content and every quiz question is available in two versions: plain-language beginner (with everyday analogies) and precise experienced (with technical detail).

All of this runs as a self-contained web dashboard — no cloud dependencies, no API keys, no build step.

## Bob Features Used

Feature / How it was used

Agent mode Orchestrated the full workflow: cloning the repo, spawning subagents, writing output files, and building the dashboard 

Parallel subagents Phase 1 (architecture analysis) and Phase 2 (hot-file detection) ran simultaneously as independent subagents, then Phase 3 (learning path generation) consumed both outputs

Plan mode*Used to scope the multi-phase workflow before implementation defining the subagent responsibilities, JSON schemas, and dashboard wiring

Adaptive content generation*A dedicated subagent read the learning path and rewrote every description and quiz question in both beginner and experienced variants, saved as a separate JSON fil

## Tech Stack

- Frontend: Plain HTML, CSS, and JavaScript — no framework, no build step
- Server: Node.js (`serve.js`) — a minimal static file server, zero dependencies
- Data pipeline: JSON files generated by AI subagents, fetched at runtime by the dashboard
- Diagram rendering: [Mermaid.js](https://mermaid.js.org/) (loaded from CDN) for the architecture flowchart
- Fonts: IBM Plex Sans + IBM Plex Mono (Google Fonts)

## How to Run Locally

bash
# 1. Clone this repository
git clone https://github.com/mohammedamaanaltafshaikh47-maker/developer-onboarding-buddy
cd developer-onboarding-buddy

# 2. Start the local server (requires Node.js — no npm install needed)
node serve.js

# 3. Open the dashboard in your browser
#    Landing page:
http://localhost:8080/dashboard/

#    Onboarding path — beginner mode:
http://localhost:8080/dashboard/onboarding.html?level=beginner

#    Onboarding path — experienced mode:
http://localhost:8080/dashboard/onboarding.html?level=experienced
```

The server serves all static files from the project root. The dashboard fetches the three JSON files in `/subagent-outputs/` at runtime no separate API or database required.


## Demo

The onboarding path in this repository was generated for the [Conduit API](https://github.com/gothinkster/node-express-realworld-example-app)a production-grade Node.js/Express/Prisma/PostgreSQL blogging platform used as a RealWorld example app.

The generated outputs live in `/subagent-outputs/`:

| File | Contents |
| `architecture.json` | App summary, tech stack, module map, data flow, Mermaid diagram, key files |
| `hot-files.json` | Top 10 most-changed files from git history, with commit counts and importance notes |
| `learning-path.json` | Original 5-day learning path with objectives, files, concepts, tasks, and quizzes |
| `learning-path-adaptive.json` | Same path with beginner and experienced variants for every description and quiz question |
